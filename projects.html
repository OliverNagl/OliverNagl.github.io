A few things I have built. Code and write-ups live in the linked repositories — these are summaries, not papers.

Mitral valve segmentation

A U-Net that segments the mitral valve in echocardiogram video, built for the Advanced Machine Learning course at ETH Zürich. The interesting part was temporal consistency: frame-independent predictions flicker badly, so the model conditions on neighbouring frames.

PyTorch·U-Net·Segmentation
GitHub

Neural operators for PDEs

Fourier neural operators for solving PDEs, a sparse-regression approach to recovering the governing equation from data, and Allen–Cahn phase-field dynamics. Final project for AI in the Sciences and Engineering. The recurring lesson was how quickly operator learning degrades out of distribution.

PyTorch·Neural operators·PDEs
GitHub

Double-solution jigsaw puzzles

Searching for jigsaw puzzles that admit exactly two non-trivial solutions, inspired by Matt Parker's "Parker puzzles". Encoded as SAT and solved with pySAT; the work is mostly in ruling out the trivial symmetry-related solutions, which is a group theory problem rather than a search problem.
